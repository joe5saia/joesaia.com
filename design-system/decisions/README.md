# Decision records

Create records as `NNNN-short-title.md` using the template below. Never rewrite
an accepted decision; supersede it with a new record.

```markdown
# NNNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD

## Context

What user or system need requires a decision?

## Decision

What is the smallest durable choice?

## Consequences

What becomes easier, harder, or intentionally unsupported?
```
