# Changelog

All notable design-system changes are recorded here.

## 1.0.0 — 2026-08-27

### Added

- Production token source for color, typography, spacing, layout, shape,
  elevation, z-index, focus, and motion.
- Reusable Button, Badge, Eyebrow, and Divider Astro primitives.
- Visual catalog covering foundations and representative component states.
- Design language, content, accessibility, component, contribution, release,
  browser-support, and decision guidance.
- Exhaustive audit of designsystemchecklist.com's 230 checklist items.

### Changed

- Consolidated duplicated homepage and global tokens without changing the
  intended visual language.
