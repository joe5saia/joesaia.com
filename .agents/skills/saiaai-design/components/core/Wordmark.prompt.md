The SaiaAI wordmark — serif "Saia" with the "AI" in gold. Text-only; for the full brand signature use `Logo` (mark + wordmark), and for the symbol alone use `BrandMark`. Never recreate the logotype ad hoc.

```jsx
<Wordmark size="md" />
<Wordmark size="sm" onDark />
```

Sizes: `sm` / `md` / `lg`. Pass `onDark` on ink backgrounds.
