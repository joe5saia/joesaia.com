The SaiaAI North Star symbol — a gold four-point guiding star with a small twinkle. Use standalone for favicons, avatars, and stamps; pair with `Wordmark` (or use `Logo`) for the full lockup.

```jsx
<BrandMark size={40} />
<BrandMark size={16} solo />   {/* favicon / tiny sizes — drops the twinkle */}
```

Always gold. Pass `solo` below ~24px so the twinkle doesn't muddy the mark.
