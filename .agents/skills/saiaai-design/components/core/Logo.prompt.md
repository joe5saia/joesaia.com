The full SaiaAI logo — North Star `BrandMark` locked up with the wordmark. The canonical brand signature; use this for headers, footers, and sign-offs.

```jsx
<Logo size="md" />
<Logo orientation="stacked" size="lg" onDark />
```

`orientation`: `horizontal` (default) or `stacked`. Sizes `sm`/`md`/`lg`. Pass `onDark` on ink backgrounds. For just the symbol use `BrandMark`; for just the text use `Wordmark`.
