Square-cornered, uppercase CTA button — use for primary actions like "Email Joe" or "Schedule a consultation".

```jsx
<Button variant="primary" href="mailto:joe5saia@gmail.com">Email Joe</Button>
<Button variant="ghost">Schedule a consultation</Button>
```

Variants: `primary` (dark fill + soft shadow, default), `ghost` (gold-outlined cream), `dark`. Sizes: `md` (default), `sm`. Pass `href` to render an anchor.
